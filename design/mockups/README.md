# design/mockups — 화면 시안 원본 (본인 제작)

팀 프론트 저장소의 `CLAUDE.md`·`docs/시안V4_대응표.md` 가 참조하는 "시안" 이 이 파일들입니다.

| 파일 | 원본명 | 범위 | 크기 |
|---|---|---|---|
| `01-onboarding.html` | 온보딩최종.html | 온보딩 5장 (첫 실행 안내 · "사장님은 …" 카피 · 진입 CTA) | 22.8 MB (에셋 번들) |
| `02-app-ui-kit.html` | 최최최종.html | **앱 본 화면 전체** (로그인/회원가입 제외) — 하단 탭 4 (홈 · 관심목록 · AI 추천 · 마이) | 0.8 MB |
| `03-auth-login-signup.html` | 로그인화면.html | 로그인 · 회원가입 · 본인 확인 · 아이디/비밀번호 찾기 · 약관 및 접근 권한 동의 | 12.3 MB (에셋 번들) |

## 02-app-ui-kit.html 에 포함된 화면 (SCREENS 정의 기준)

- **홈 피드** — 트렌드 숏폼 카드 · 정상/로딩/네트워크 오류/빈 상태 4종
- **AI 추천 대화** — 주제 선택("어떤 주제를 찍고 싶으세요?": 신메뉴 · 기존메뉴 · 이벤트 · 매장홍보) → 조건 칩(1인 촬영 · 얼굴 노출 없음 · 촬영 10분 · 내레이션 필요 …) → 추천 결과 카드(a1~a6)
- **촬영 준비 · 카메라 · 안무 가이드** — 컷 태스크(t1 간판 클로즈업 · t2 손으로 집기 · t3 절단면 · t4 리액션) 순서 안내
- **AI 자동 편집** — 단계 표시(컷 편집 → 흔들림 효과 → 자막 → 위치 태그·브랜딩 → 최종 렌더링) · 시간 초과/시스템 오류 상태
- **숏폼 미리보기 · 내보내기** — Instagram · YouTube · 카카오톡 · 파일 · 비디오 저장 · 링크 복사
- **매장 등록** — "매장 정보를 등록해 주세요" (지도 검색, 매장 목록 s0~s6 샘플)
- **매장 인사이트** — 주간 조회수 추이 · 주요 방문층 · 지역 상권 분석 · 다음 숏폼 추천
- **관심 목록 · 마이페이지 · 앨범 · 설정 · FAQ · 플랜 안내(Reals. Pro)**
